## Gotchas for the next agent
- The Android project is opened in Android Studio from `src/GameLauncher.Companion`. It is **not** in the .NET solution.
- Gradle JDK must be 17–23. Android Studio's bundled JDK 25 breaks Gradle 8.13.
- `GameCard` catches all cover exceptions and returns `null`, so a broken cover shows only as a title placeholder. Add temporary logging there when debugging covers.
- Status strings are `Stopped`/`Starting`/`Running`/`Stopping` (strings, not enum ordinals). The UI only labels the last three.
- Shortcut/Steam entries only report Running if a **tracking executable** is set on the game's Edit page in Windows.
