# Launchpad 1.5.1 — Windows installer

## Included changes

- Companion game-stop endpoints: request normal close or explicitly selected force stop of one exactly matched game executable. Refuse ambiguous/inaccessible matches, Steam and Launchpad; no process-tree termination or file deletion. Updated Android source supplies the controls but must be built separately; no Android APK is produced by this installer script.
- LB/RB move backward/forward by one-third of the current filtered/sorted game list with smooth scrolling and first/last-entry bounds. The owner confirmed this behavior works before packaging.
- L2/R2 (LT/RT) cycle Games, Emulators and Tools on dashboards; held triggers require release before another switch. Runtime verification remains pending.
- README documents controller mappings, remote-stop limitations, companion setup links and local artwork copying/storage.
